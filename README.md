# Infectious Diseases Challenge

Static GitHub Pages web app: 10 sets × 10 questions, 30 seconds/question, instant answer reveal, feedback after each set.

## Files
- index.html
- style.css
- app.js

## Deploy
Upload these files to the root of an existing GitHub repository and enable GitHub Pages from the `main` branch / root folder.
